Notifications

Enable to receive activity alerts by email. Login links will arrive regardless of this setting.

Alerts for every issue and merge request on those repositories. A watch or mute on a repository has priority over this setting.

Notification text is sent in full, including for private repositories, so a repository name and item number reach Apple and appear on a lock screen.

Export

Your profile, repositories, issues and merge requests as one JSON bundle, the same one gitbay account export writes. Keys are never included; a replayed bundle's emails arrive unverified.

On the command line

No page here yet, and nothing refusing one: a credential is easier to pipe than to paste, and a minted token is shown once.

gitbay auth token create --name laptop # API tokens
gitbay web sessions list               # browser sessions
gitbay admin ...                       # instance administration

All of it works from stock OpenSSH too: ssh git@{{.Host}} auth whoami.

{{end}}
